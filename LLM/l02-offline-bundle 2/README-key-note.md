## API key handling

Copy `.env.example` to `.env` in the repository root and keep your personal key there.
The `.gitignore` excludes `.env`, so the local file is not committed.
Never paste a key into code, a notebook, a screenshot, a chat or a commit.
If a key reaches GitHub, tell the school coordinator immediately so it can be revoked.
Deleting the commit does not remove a key from Git history; revoke it first.
